# health-chatbot

This repository contains two projects:

## 1. Health Chatbot
A simple health chatbot using Flask, JavaScript, and basic NLP.

### Running the Health Chatbot
```bash
pip install -r requirements.txt
python app.py
```

Visit `http://localhost:5000` to use the chatbot.

## 2. Video Browser 🎬
A responsive single-page application (SPA) for browsing and playing videos, built with React, TypeScript, and TailwindCSS.

### Features
- Grid layout displaying video thumbnails, titles, and durations
- Search functionality to filter videos by title or genre
- Video details page with embedded player
- Like/unlike videos with localStorage persistence
- Fully responsive design for mobile and desktop
- "Load More" pagination
- Accessibility features (keyboard navigation, ARIA roles)

### Running the Video Browser
```bash
cd video-browser
npm install
npm run dev
```

Visit `http://localhost:5173` to browse videos.

For detailed documentation, see [video-browser/README.md](video-browser/README.md)
